# Plotted :: Canadian catalogue seed
#
# One title per line. Blank lines and lines starting with # are ignored.
# Each entry is resolved through TMDB search and ingested with its Canadian
# availability, exactly as a user adding it by hand would be.
#
#     make seed          (needs TMDB_READ_ACCESS_TOKEN and a running database)
#
# WHAT THIS IS, HONESTLY
#
# Section 7.3 of the specification asks for roughly 500 titles, hand-verified,
# with correct prices and deep links. This file is not that yet. It is a
# starting set chosen to span the Canadian services and the awkward cases --
# Canadian originals, public broadcasters, prestige cable, anime, subtitled
# film, older titles that have drifted between services -- so that the coverage
# numbers it produces are informative rather than flattering.
#
# Growing it to 500 is manual work and deliberately so: the point of a curated
# seed is that a person checked it. Add titles you would actually watch, run
# the seed, and check the availability that comes back against the provider's
# own app. Where they disagree, that disagreement is the interesting data --
# record it through the availability-correction endpoint rather than editing
# the row.
